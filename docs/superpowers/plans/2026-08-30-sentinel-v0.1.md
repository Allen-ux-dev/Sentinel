# Sentinel v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a native bilingual macOS Sentinel v0.1 with the vector eye engine, real-lock-screen overlay integration, local monitors/timeline, and bounded watchdog recovery.

**Architecture:** Pure behavior lives in `SentinelCore` and is tested independently. The `Sentinel` executable owns macOS UI/monitors and uses a narrow overlay bridge to SkyLightWindow; `SentinelHelper` uses shared files for heartbeat/recovery without touching UI state.

**Tech Stack:** Swift 6, SwiftUI, AppKit, Network, IOKit, ApplicationServices, Swift Package Manager, SkyLightWindow (macOS only), XCTest/Swift Testing.

**Spec:** `docs/superpowers/specs/2026-08-30-sentinel-v0.1-design.md`

## Global Constraints
- Native macOS only for the app UI; no Electron/WebView.
- macOS authentication remains system-owned; never capture password/key/fingerprint content.
- Chinese and English switching is required in v0.1.
- Event data stays local in v0.1.
- SkyLight/private API failure must not break locking, unlocking, or monitoring.
- Default authentication threshold: 3 failures in 120 seconds.
- Default high alert duration: 10 seconds.
- Default event retention: 7 days.
- Default watchdog budget: 3 recovery attempts per 5 minutes.
